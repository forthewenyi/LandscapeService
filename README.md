# Landscaping Service

A responsive static website for a family landscaping service offering tree and
lawn care, gardens and planting, patios and hardscapes, decks, and fences across
Austin and surrounding communities.

## Design

The site uses a Texas Modern palette of cedar green, warm plaster, pale
limestone, sage, and burnt orange. Its editorial layout features a condensed
display typeface, four linked service families, real project photography,
project filters, and an interactive before-and-after comparison.

## Files

- `index.html` contains the page structure and content.
- `styles.css` contains the responsive layout and visual system.
- `script.js` contains navigation, reveal, filtering, comparison, and quote behavior.
- `assets/` contains the locally stored landscaping photography.

Open `index.html` directly or serve this directory with any static web server.
